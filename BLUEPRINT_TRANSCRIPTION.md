# MAP Grade-Level Blueprint Transcription

Status date: **2026-08-22**

This document separates facts confirmed directly by current Missouri DESE web resources from category-range values that have been visually transcribed from an accessible Missouri MAP Grade-Level blueprint copy.

## Evidence state

### Current DESE primary-source confirmed

- The current DESE Grade-Level page links **MAP Grade-Level Assessment Blueprints** as the governing blueprint resource.
- The DESE blueprint wrapper currently resolves to an April 2026 file named `MAP Grade-Level Assessment Blueprints_AOD.pdf`.
- The current DESE Guide confirms the following complete assessment point totals:
  - Mathematics Grades 3-5: 48 points each.
  - Mathematics Grades 6-8: 54 points each.
  - ELA Grades 3-6 and 8: 56 points each.
  - ELA Grade 7: 52 points.
  - Science Grades 5 and 8: 60 points each.
- Current DESE resources define Grade-Level forms as potentially containing SR, EBSR, CR, WT, PE, and TE item types.

### Category-range transcription evidence

The tables below were visually transcribed from an accessible Missouri Grade-Level blueprint PDF copy whose point totals and blueprint organization match the current DESE totals. In the available review environment the current DESE April 2026 PDF is served through an HTML PDF.js wrapper, so a direct visual comparison of the primary file could not be completed.

Therefore:

- the values below are **strong corroborating evidence**;
- they are suitable for architecture planning, bank-gap diagnostics, and clean-room verification targets;
- they are **not yet sufficient on their own** to set a production blueprint `verified: true` flag;
- current-DESE primary-file confirmation is still required before release promotion.

## Execution implications for this repository

These official/full-test ranges must not be collapsed into the current auto-scored development draw.

1. **ELA** — complete operational forms include writing and speaking/listening contributions. Those components are currently deferred in the static application. A reading/research/language-only generated form is therefore a supported practice subset, not a complete 52/56-point MAP form.
2. **Science** — the operational assessment includes constructed-response work. Until the app can represent and score that component faithfully, a 60-point all-auto-scored synthetic form must not be labeled as an operationally complete simulation.
3. **Mathematics** — the blueprint assigns a fixed 6-point PE contribution in Grades 3-5 and 8 points in Grades 6-8. The current development PE bank deliberately delivers one coherent practice event, but most current event bundles do not yet total the full official PE point contribution. Full-form execution therefore remains blocked until complete 6/8-point event bundles exist.

## Promotion rule

An assessment can move from development practice toward complete-form release only after a clean-room reviewer:

- independently retrieves the current DESE blueprint;
- confirms every category/range value against the current primary file;
- verifies the bank's tags against the category model;
- verifies every deferred component is explicitly represented in the product contract;
- confirms the executable form builder is not substituting auto-scored material for missing official components; and
- runs the required 5,000 blueprint-constrained form and retake-pair audit on the exact candidate tree.
