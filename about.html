About this project

This is an unofficial, original Missouri MAP Grade-Level practice application. It is designed to reflect current MAP session structure, calculator rules, untimed timing guidance, grade-level standards, and supported response styles without copying secure or released official question wording.

What a practice session is

The app draws a short practice set of up to 12 supported items from the selected session's item pool. That is useful for focused practice, but it is not the same as taking a complete operational MAP form. The official point target shown before a session describes the summative assessment, not the number of points in the short practice set.

Current release limitations

Audio/listening and automatic human-judgment scoring are intentionally outside this release. ELA listening is not playable, Grades 4 and 8 ELA long-form writing is not included as an automatically scored practice component, and written parts of Math performance events remain a fidelity limitation. Science practice can include constructed-response prompts: your written response is saved in your browser and shown after submission for manual review, but the site does not automatically grade that prose or include those points in the automatic percentage.

Public DESE materials establish that both Science sessions contain constructed-response, multiple-choice, and technology-enhanced items, but the current public blueprint does not state a separate fixed summative constructed-response point quota. The project therefore does not invent an auto/manual point split merely to claim a complete Science form.

No missing listening, writing, constructed-response scoring, or written performance-event component is replaced with extra multiple-choice questions and described as a complete operational MAP simulation.

Scoring

Results are raw practice points and strand summaries. Automatically scored points are reported separately from any written-response points that require human review. They are not official MAP scale scores or proficiency classifications.

Privacy

Practice state is stored locally in your browser. This static application has no account system or server-side student database.
